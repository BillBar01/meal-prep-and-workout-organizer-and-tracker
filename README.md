# Meal Prep & Workout Organizer

A personal planner for keto weekday meal prep (and, later, workouts).

## Meal prep (v1)

`index.html` is a single-file web app with no build step:

- **Plan**: pick the week's lunch meal-prep recipe, dinners, breakfast days and snacks.
- **Shop**: grocery checklist grouped by store aisle, a staples check before you leave, custom items, and a trip log comparing Giant receipts to a usual Whole Foods week.
- **Prep**: Sunday step-by-step lunch prep with built-in timers.
- **Dinners**: quick protein + vegetable recipes with steps and timers.

All recipes are peanut- and tree-nut-free; items that sometimes carry "may contain" warnings are flagged.

Open `index.html` in a browser to use it locally (saves to that browser). The hosted copy syncs across devices.

Recipes, dinners and the grocery catalog live at the top of the `<script>` block (`CAT`, `LUNCH`, `DINNER`) — edit them there.
